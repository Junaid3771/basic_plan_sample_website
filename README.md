# Basic — ₹6,500 | Thanal Builders demo

A simple, desktop-first construction company landing page for Kerala. Fictional business; sample copy, text-based logo and stock photograph stand in for client-provided materials.

## Deploy from your own Git repository to Vercel

1. Put **the contents of this folder** at the root of its own repository. Keep `index.html`, `styles.css`, `assets/` and `vercel.json` together.
2. Push to the Git account/repository you choose.
3. Import that repository into a new Vercel project.
4. Framework preset: **Other**. Root directory: **repository root**. Build command: **empty**. Install command: **empty**. Output directory: **`.`**. The included `vercel.json` already sets these options.
5. Deploy. No npm install, framework, backend, environment variables or build step is required.

Reference: [Vercel static site builds](https://vercel.com/docs/builds/configure-a-build).

## Local preview

Open `index.html` in a browser. Alternatively, run `python -m http.server 4173` from this folder and visit `http://localhost:4173`.

## Package coverage

- One static HTML/CSS landing page; **exactly three main sections**: introduction, services, contact.
- Clean design, business information, contact information, simple navigation and a contact-section CTA.
- Desktop-focused two-column layout; a small CSS fallback keeps text readable on narrow screens.
- No JavaScript, animation, form, chat widget, payment integration or extra pages.
- Hosting/deployment and one minor revision are delivery-service terms, not website controls. Hosting has not been activated; deployment follows your Git/Vercel process. Hosting cost/eligibility depends on the hosting plan you select.

## Replace for a real client

Edit the business name, copy, logo, phone, email, address and opening hours in `index.html`; replace `assets/home.jpg` with the client's supplied image. The CTA currently scrolls to contact details. Reserved `.example` email and masked phone are intentional and do not contact anyone.
